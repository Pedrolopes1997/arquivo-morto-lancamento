# Arquivo Morto — aviso de versão

**Arquivo Morto** é um jogo de investigação e terror psicológico em primeira pessoa, do **WeCare Studios**.
Página do jogo: **https://wecarestudios.itch.io/arquivo-morto**

Este repositório não tem o código nem os instaladores do jogo. Ele guarda só o aviso de versão nova
(`atualizacao.json`, nas releases) que o jogo consulta ao abrir. Quem comprou baixa a versão nova pela página do
itch.io; pelo app do itch, a atualização é automática.

---

**Arquivo Morto** is a first-person investigation and psychological horror game by **WeCare Studios**.
Game page: **https://wecarestudios.itch.io/arquivo-morto**

This repository holds neither the game's code nor its installers — only the new-version notice
(`atualizacao.json`, in the releases) that the game checks when it opens. If you bought the game, download new
versions from its itch.io page; with the itch app, updates are automatic.
